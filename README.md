🧮 Python Calculator Mini Project

This is a Python mini project created using functions, loops, and match-case statements.
The calculator performs multiple mathematical operations based on user input.

🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Modulus
- Floor Division
- Square
- Square Root
- Even/Odd Check
- Maximum Number Finder
- Swap Numbers
- Exit Option

📚 Concepts Used

- Python Functions
- Match-Case Statements
- Loops
- Conditional Statements
- User Input
- Error Handling
- f-Strings
- Mathematical Operations

⚠️ Error Handling

The program handles:

- Division by zero
- Modulus by zero
- Floor division by zero
- Invalid operation numbers

▶️ Sample Output

addition of 12 & 3 is 15
division of 12 & 3 is 4.00
sqrt of 12 is 3.46
12 is even
after swapping: 3 & 12
